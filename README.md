## Задание 1 — генератор паролей

Консольная программа: спрашивает длину, собирает случайный пароль из латинских букв и цифр и выводит его.

Пара моментов, которые я добавил от себя:
- если ввести не число, ноль или что-то странное, программа не падает, а просто просит ввести ещё раз;
- пароль всегда содержит хотя бы одну букву и одну цифру (если длина 2 и больше);
- для случайности используется модуль `secrets`, а не `random` — он как раз предназначен для паролей.

### Как запустить

```bash
cd task-1
python password_generator.py
```

Пример:

```
Генератор паролей | Шкель Антон ПрИнж25-1
Введите длину пароля: 12
Ваш пароль: 4hTqP9xLm2Ra
```

## Задание 2 — Telegram-бот

Выбрал первую вариацию. Бот написан на **aiogram 3** и умеет две команды:

| Команда  | Что делает |
|----------|------------|
| `/start` | здоровается и рассказывает, что умеет |
| `/swaga` | присылает случайную строчку из трека «ДИНАСТИЯ» — madk1d |

Строчки бот берёт из файла `task-2/lyrics.txt` — по одной на строку. Так текст не зашит в код, и его легко поменять.

### Как запустить

1. Получить токен у [@BotFather](https://t.me/BotFather) и положить его в `task-2/.env`:
   ```bash
   cd task-2
   cp .env.example .env    # и вписать BOT_TOKEN=...
   ```
   Файл `.env` в репозиторий не попадает (он в `.gitignore`).
---
2. Установить зависимости и запустить:
   ```bash
   cd task-2
   pip install -r requirements.txt
   python bot.py
   ```

Если в консоли появилось «Бот запущен» — можно писать ему в Telegram.

## Задание 3 — запуск через Docker

В папке `task-3` лежат `Dockerfile` и `docker-compose.yml`. Образ собирается на основе `python:3.12-slim`, внутрь копируется бот из `task-2`. Токен в образ не попадает — он подтягивается из `task-2/.env` при запуске.

Контейнер стоит с `restart: unless-stopped`, так что на сервере бот сам поднимется после перезагрузки или падения.

### Как запустить

Нужен установленный Docker. Сначала сделай пункт 2 из задания 2 (файл `.env` с токеном), потом:

```bash
cd task-3
docker compose up -d --build
```

команды:

```bash
docker compose logs -f   # посмотреть логи
docker compose down      # остановить
```

Без compose тоже можно, из корня репозитория:

```bash
docker build -f task-3/Dockerfile -t swaga-bot .
docker run -d --env-file task-2/.env --name swaga-bot swaga-bot
```
